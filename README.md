# AI-Assisted IT Help Desk and Incident Management

## Project Overview
This portfolio project simulates a real-world IT help desk using AI-assisted incident triage, troubleshooting, and incident management.

## Project Objectives
- Create and manage IT support incidents.
- Assess incident impact, urgency, and priority.
- Use AI to assist with technical troubleshooting.
- Develop knowledge base articles.
- Practice ServiceNow ITSM concepts.
- Review AI recommendations for accuracy.

## Tools and Technologies
- GitHub
- Markdown
- ChatGPT
- ServiceNow University
- IT Service Management (ITSM)

## Project Status
In Progress

## Career Goal
To develop practical skills for an entry-level AI Support Specialist, ServiceNow Support Analyst, or Technical Support Specialist position.

## Disclaimer
This project uses fictional support incidents for educational and portfolio purposes.
